Le site est à la **racine** du dépôt (`index.html`). Sur Vercel :

- Build command : **(vide)**

## Lancer en local

Option 1 : ouvrir `index.html` dans le navigateur.

Option 2 (recommandé) : serveur local

```bash
python -m http.server 5173
```

Puis ouvrir `http://localhost:5173`.
